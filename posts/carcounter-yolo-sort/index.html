PART 1 Vision Pipeline Architecture & Design

Traffic monitoring on multi-lane highways requires counting high-speed vehicles accurately without double-counting caused by frame dropping, temporary occlusions, or vehicle lane changes. This project combines state-of-the-art YOLOv8/YOLO11 object detection with the Simple Online and Realtime Tracking (SORT) algorithm.

The pipeline processes video frames at 60+ FPS on CUDA-enabled GPUs, maintaining unique persistent IDs across occlusions and triggering count increments when vehicle centroids intersect a designated virtual polygon boundary.

PART 2 Deep Learning Object Detection with YOLO

We deploy Ultralytics YOLO with a custom class filter focusing strictly on vehicle categories: [2: car, 3: motorcycle, 5: bus, 7: truck] from the COCO dataset. Non-road regions are masked out using a binary polygon mask, reducing inference false positives by over 90%.

from ultralytics import YOLO
import cv2

model = YOLO("yolov8n.pt") # or yolo11n.pt
mask = cv2.imread("mask.png")

# Mask applied frame inference
img_region = cv2.bitwise_and(frame, mask)
results = model(img_region, stream=True)

PART 3 SORT Tracker & Kalman State Estimation

Raw detections vary slightly across consecutive frames. The SORT tracker represents each vehicle target with an 8-dimensional state vector:

$$\mathbf{x} = [u, v, s, r, \dot{u}, \dot{v}, \dot{s}, \dot{r}]^T$$

where $(u, v)$ is the 2D bounding box center, $s$ is the scale (area), and $r$ is the aspect ratio. The Kalman filter predicts target positions in frame $k$, and the Hungarian algorithm computes optimal bipartite matching based on the Intersection-over-Union (IoU) cost matrix.

PART 4 Virtual Counting Line & Trajectory Vector Math

A virtual detection line segment $L = \{(x_1, y_1), (x_2, y_2)\}$ is placed across the highway lanes. When vehicle centroid $C(x, y)$ moves across consecutive frames, a line intersection test checks whether the trajectory vector $\vec{v} = C_k - C_{k-1}$ intersects line $L$.

# Vector cross-product sign test for line crossing
def ccw(A, B, C):
    return (C[1]-A[1]) * (B[0]-A[0]) > (B[1]-A[1]) * (C[0]-A[0])

def intersect(A, B, C, D):
    return ccw(A, C, D) != ccw(B, C, D) and ccw(A, B, C) != ccw(A, B, D)

PART 6 Performance Benchmarks & Edge Deployment

  • Inference Speed: 62.4 FPS on NVIDIA RTX 3060 Laptop (1080p resolution).
  • Counting Accuracy: 95.2% on standard 10-minute highway stress video (over 1,400 vehicles evaluated).
  • Zero Duplicate Counts: Persistent ID tracking prevents re-counting slow or lingering vehicles.
