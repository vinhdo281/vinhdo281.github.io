PART 1 Hand Kinematic Skeleton & Landmark Graph

Counting raised fingers in video streams requires determining whether each finger is extended or curled. MediaPipe identifies 21 landmarks organized along 5 kinematic chains originating at the wrist (Landmark 0).

PART 2 Finger State Classification Algorithm

For the four primary fingers (Index, Middle, Ring, Pinky), extension is determined by comparing the vertical y-coordinate of the tip landmark with its corresponding Proximal Interphalangeal (PIP) joint:

# Finger tips: [8, 12, 16, 20]
# Finger PIPs: [6, 10, 14, 18]
# In image coordinates, y=0 is at the TOP, so a raised finger has y_tip < y_pip:
is_extended = lm_list[tip_id][2] < lm_list[pip_id][2]

PART 3 Thumb Handedness Logic (Left vs Right Hand)

Because the thumb moves laterally across the palm plane, vertical comparisons fail. Instead, we use horizontal x-coordinates calibrated against hand label classification (Left vs Right Hand):

if hand_label == "Right":
    thumb_extended = lm_list[4][1] < lm_list[3][1]
else:
    thumb_extended = lm_list[4][1] > lm_list[3][1]

PART 4 Full Python Implementation with OpenCV

import cv2
import mediapipe as mp

cap = cv2.VideoCapture(0)
mp_hands = mp.solutions.hands
hands = mp_hands.Hands(max_num_hands=2, min_detection_confidence=0.75)
tip_ids = [4, 8, 12, 16, 20]

while cap.isOpened():
    ret, frame = cap.read()
    if not ret: break
    frame = cv2.flip(frame, 1) # Mirror preview
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
