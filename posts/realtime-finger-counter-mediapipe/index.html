PART 1 Hand Kinematic Skeleton: MCP, PIP, DIP & Tip Hierarchy

Reliable finger counting requires mapping human hand anatomy to mathematical vectors. MediaPipe predicts 21 3D landmarks ($x, y, z$) structured along 5 kinematic chains rooted at Landmark 0 (Wrist):

  • MCP (Metacarpophalangeal Joint): Knuckle base joints: Landmarks $[1, 5, 9, 13, 17]$.
  • PIP (Proximal Interphalangeal Joint): Middle articulation joints: Landmarks $[2, 6, 10, 14, 18]$.
  • DIP (Distal Interphalangeal Joint): Outermost knuckle joints: Landmarks $[3, 7, 11, 15, 19]$.
  • TIP (Fingertips): Distal extremities: Landmarks $[4, 8, 12, 16, 20]$.

PART 2 The Four-Finger Vertical Test: Why y_tip < y_pip in Image Space?

In standard digital image matrices, the coordinate origin $(0, 0)$ is situated at the TOP-LEFT corner. The horizontal x-axis increases to the right, and the vertical y-axis increases downwards towards the bottom of the screen.

When a person raises a finger upright in front of a camera:

  • The fingertip is located higher on the display than its base knuckle.
  • Higher vertical position corresponds to a smaller pixel y-value.
  • Therefore, the condition for an extended upright finger is: $$y_{\\text{tip}} < y_{\\text{pip}}$$ 
# Finger Tip IDs: [8 (Index), 12 (Middle), 16 (Ring), 20 (Pinky)]
# Finger PIP IDs: [6 (Index), 10 (Middle), 14 (Ring), 18 (Pinky)]
fingers_state = []
for tip_id, pip_id in zip([8, 12, 16, 20], [6, 10, 14, 18]):
    # Extended if tip is higher up (smaller y) than PIP knuckle:
    if lm_list[tip_id][2] < lm_list[pip_id][2]:
        fingers_state.append(1)
    else:
        fingers_state.append(0)

PART 3 The Thumb Dilemma: Why Vertical Logic Fails & Handedness Math

Applying the vertical test ($y_{\\text{tip}} < y_{\\text{pip}}$) to the thumb produces constant false states. The thumb has only two phalanges and moves laterally in the coronal plane. An extended thumb in a relaxed hand frequently has $y_4 > y_3$!

The thumb's extension must be judged along the horizontal x-axis, which depends strictly on whether the hand is a Left Hand or Right Hand:

Handedness Vector Inversion Rule (Palm facing camera):
  • Right Hand: The thumb extends laterally to the left side of the palm $\implies x_{\\text{tip}} < x_{\\text{ip}}$ ($x_4 < x_3$).
  • Left Hand: The thumb extends laterally to the right side of the palm $\implies x_{\\text{tip}} > x_{\\text{ip}}$ ($x_4 > x_3$).

Watch out for camera mirroring! When displaying a mirrored preview (cv2.flip(frame, 1)), the camera transforms a user's right hand into a visually apparent left hand. MediaPipe's handedness label results.multi_handedness[i].classification[0].label reflects the mirrored view and must be inverted if camera mirroring is applied.

PART 4 Angle-Invariant Dot Product Test for Tilted Hands

What if the user holds their hand at a $45^\\circ$ angle, or horizontally? Comparing simple 1D coordinates ($y$ or $x$) fails because gravity no longer aligns with the hand coordinate axis!

To achieve true 360-degree rotation invariance, we calculate the dot product between the proximal vector $\\vec{u} = \\text{PIP} - \\text{MCP}$ and distal vector $\\vec{v} = \\text{TIP} - \\text{PIP}$:

$$\\cos \\theta = \\frac{\\vec{u} \\cdot \\vec{v}}{\\|\\vec{u}\\| \\cdot \\|\\vec{v}\\|}$$

  • Straight extended finger: Vectors $\\vec{u}$ and $\\vec{v}$ are collinear $\implies \\cos\\theta \\approx 1.0$ (angle $\\theta < 25^\\circ$).
  • Curled / closed finger: Vector $\\vec{v}$ folds backward toward the palm $\implies \\cos\\theta < 0.2$ (angle $\\theta > 75^\\circ$).

PART 5 Multi-Hand Dual Counting (0 to 10) Architecture

When multiple hands are in the scene, MediaPipe processes each detection independently. To display consistent left-to-right on-screen counts, hands are sorted by their wrist x-coordinate ($lm_0.x$):

PART 6 Annotated Python Script with Cyberpunk HUD Rendering

import cv2
import mediapipe as mp

mp_hands = mp.solutions.hands
hands = mp_hands.Hands(max_num_hands=2, min_detection_confidence=0.75, min_tracking_confidence=0.75)
tip_ids = [4, 8, 12, 16, 20]
pip_ids = [2, 6, 10, 14, 18]

cap = cv2.VideoCapture(0)
while cap.isOpened():
    ret, frame = cap.read()
    if not ret: break
    frame = cv2.flip(frame, 1) # Mirror preview
    h, w, c = frame.shape
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    res = hands.process(rgb)

    total_extended = 0
    if res.multi_hand_landmarks:
        for i, hand_lms in enumerate(res.multi_hand_landmarks):
            handedness = res.multi_handedness[i].classification[0].label
            lm = hand_lms.landmark
            fingers = []

            # Thumb logic (horizontal comparison with handedness)
            if handedness == "Right":
                fingers.append(1 if lm[4].x < lm[3].x else 0)
            else:
                fingers.append(1 if lm[4].x > lm[3].x else 0)

            # Four primary fingers (vertical comparison)
            for tip, pip in zip([8, 12, 16, 20], [6, 10, 14, 18]):
                fingers.append(1 if lm[tip].y < lm[pip].y else 0)

            total_extended += sum(fingers)

    # Cyberpunk HUD display
    cv2.rectangle(frame, (20, 20), (170, 120), (10, 10, 20), cv2.FILLED)
    cv2.rectangle(frame, (20, 20), (170, 120), (0, 242, 254), 2)
    cv2.putText(frame, f"{total_extended}", (55, 100), cv2.FONT_HERSHEY_SIMPLEX, 2.5, (0, 242, 254), 4)
    cv2.imshow("Cyberpunk Finger Counter", frame)
    if cv2.waitKey(1) & 0xFF == ord('q'): break

TEIL 1 Handskelett-Kinematik: MCP, PIP, DIP & Spitzen-Hierarchie

MediaPipe liefert 21 3D-Landmarken je Hand, unterteilt in MCP (Fingergrundgelenke), PIP (Mittelgelenke), DIP (Endgelenke) und Spitzen.

TEIL 2 Der 4-Finger-Vertikaltest: Warum y_tip < y_pip im Bildraum?

Im Bildkoordinatensystem liegt der Ursprung oben links ($y$ wächst nach unten). Ein nach oben ausgestreckter Finger liegt optisch höher und besitzt daher einen kleineren $y$-Pixelwert: $y_{\\text{tip}} < y_{\\text{pip}}$.

TEIL 3 Das Daumen-Dilemma: Warum Vertikallogik versagt & Händigkeitsmathematik

Der Daumen bewegt sich lateral in der Handfläche. Ein vertikaler Test scheitert. Die Auswertung erfolgt auf der horizontalen x-Achse: Bei der rechten Hand gilt $x_{\\text{tip}} < x_{\\text{ip}}$, bei der linken Hand $x_{\\text{tip}} > x_{\\text{ip}}$.

TEIL 4 Winkelinvarianter Skalarprodukt-Test für geneigte Hände

Über das Skalarprodukt der Vektoren $\\vec{u} = \\text{PIP} - \\text{MCP}$ und $\\vec{v} = \\text{TIP} - \\text{PIP}$ lässt sich der Streckungsgrad unabhängig von der Handneigung ($360^\\circ$ rotationsinvariant) bestimmen.
