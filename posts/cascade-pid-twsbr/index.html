PART 1 Dynamic Modeling & Inverted Pendulum Physics

A Two-Wheeled Self-Balancing Robot (TWSBR) is a nonlinear, underactuated, non-minimum phase mechatronic system. It possesses 3 degrees of freedom (chassis pitch angle $\theta$, wheel angular positions $\phi_L, \phi_R$, and heading yaw $\psi$), but actuation is provided solely by two DC brushless/stepper motors generating torques $\tau_L, \tau_R$.

Using the Euler-Lagrange equations of motion, the system can be linearized around the unstable vertical equilibrium point $(\theta = 0, \dot{\theta} = 0)$:

% Linearized State-Space Formulation around theta = 0:
% State vector: x = [position; velocity; pitch_angle; pitch_rate]^T
% dx/dt = A*x + B*u
% y     = C*x + D*u

The total inertia matrix $M(q)$ couples the linear acceleration of the wheel base $\ddot{x}$ directly into the angular acceleration of the body $\ddot{\theta}$. When the chassis pitches forward ($+\theta$), the wheels must accelerate forward ($+\ddot{x}$) to generate a corrective inertial reaction torque restoring vertical balance.

Core Insight: You cannot stabilize position without modulating pitch angle. Therefore, a single-loop PID controller fails because position error and pitch error require opposite control directions. The dual-loop cascade topology is mathematically essential.

PART 2 Dual-Loop Cascade Control Architecture (500Hz / 50Hz)

The control architecture decouples the dynamics into two distinct frequency regimes:

  • Fast Inner Loop (Attitude / Balance Loop - 500 Hz): Operates on pitch angle error $e_\theta = \theta_{\text{ref}} - \theta$ and pitch rate $\dot{\theta}$. Outputs motor voltage/PWM torque command $\tau$.
  • Slow Outer Loop (Position / Velocity Loop - 50 Hz): Operates on cart linear displacement error $e_x = x_{\text{ref}} - x$ and linear velocity $\dot{x}$. Outputs the reference tilt angle $\theta_{\text{ref}}$ fed to the inner loop.
% Mathematical Equations:
% Inner Loop: tau(t) = Kp_theta * (theta_ref - theta) + Kd_theta * (0 - theta_dot)
% Outer Loop: theta_ref(t) = Kp_x * (x_ref - x) + Ki_x * integral(x_ref - x) + Kd_x * (0 - x_dot)
% Saturation clamp: theta_ref = max(-12 deg, min(+12 deg, theta_ref))

By enforcing a strict bandwidth separation (inner loop is $10\times$ faster than outer loop), the inner loop views $\theta_{\text{ref}}$ as a quasi-static setpoint, preventing destabilizing high-frequency resonance between wheels and chassis.

PART 3 MATLAB & Simulink Model Implementation (Simulation_TWSBR.slx)

The nonlinear physics plant is implemented in Simulation_TWSBR.slx, incorporating realistic actuator constraints:

  • Motor back-EMF voltage saturation ($\pm 12\text{V}$ H-bridge limits).
  • Coulomb & viscous friction coefficients at the wheel-ground contact interface.
  • Sensor noise injection (Gaussian white noise on accelerometer and gyroscope channels).
  • Actuator quantization and discrete-time sampling effects.

PART 4 ESP32 FreeRTOS Firmware & Sensor Fusion Implementation

The embedded implementation runs on a dual-core ESP32 micro-controller under FreeRTOS. An MPU6050 6-DOF IMU communicates via hardware I2C at 400kHz.

// FreeRTOS Task Architecture:
// Core 1: High-Priority Fast Control Task (Period: 2ms / 500Hz)
void BalanceTask(void *pvParameters) {
    TickType_t xLastWakeTime = xTaskGetTickCount();
    const TickType_t xFrequency = pdMS_TO_TICKS(2);
    
    for(;;) {
        // 1. Read MPU6050 & apply Complementary Filter
        float dt = 0.002f;
        float gyro_rate = read_gyro_y();
        float accel_angle = atan2f(read_accel_x(), read_accel_z()) * 57.29577f;
        pitch_angle = 0.98f * (pitch_angle + gyro_rate * dt) + 0.02f * accel_angle;
        
        // 2. Compute Inner Loop Torque
        float torque_pwm = Kp_pitch * (theta_ref - pitch_angle) - Kd_pitch * gyro_rate;
        apply_motor_pwm(torque_pwm);
        
        vTaskDelayUntil(&xLastWakeTime, xFrequency);
    }
}

PART 5 Systematic Tuning Protocol & Anti-Windup Strategy

Tuning a cascade balance controller requires a disciplined, sequential approach:

  1. Step 1 (Isolate Inner Loop): Set outer loop gains ($K_p^x, K_i^x, K_d^x$) to zero. Set $\theta_{\text{ref}} = 0$. Hold the robot upright and slowly increase $K_p^\theta$ until the robot resists tilt and starts oscillating mildly.
  2. Step 2 (Damp the Oscillation): Increase $K_d^\theta$ until the oscillation is critically damped and the robot stiffly maintains balance when disturbed manually.
  3. Step 3 (Engage Outer Velocity Loop): Enable $K_d^x$ to introduce wheel-speed damping, preventing the robot from running away across the table.
  4. Step 4 (Engage Position Loop with Clamp): Add $K_p^x$ to pull the robot back to origin $x = 0$. Strictly limit $\theta_{\text{ref}} \in [-12^\circ, +12^\circ]$ so a large position displacement never requests a pitch that causes wheel slippage or tipping over.
  5. Step 5 (Integral Action with Conditional Clamping): Introduce small $K_i^x$ only when $|e_x| < 0.2\text{m}$ to cancel steady-state drift without causing integrator windup during large maneuvers.

PART 6 Experimental Push-Recovery Verification & Benchmarks

The controller was verified against sudden impulsive lateral force perturbations in both Simulink and real-world physical hardware:

  • Impulse Disturbance: Instantaneous 20N horizontal push applied at chassis center of mass.
  • Recovery Settling Time ($t_s$): Less than 1.25 seconds to return to vertical with zero overshoot oscillations.
  • Stationary Drift: Cart position held within $\pm 0.005\text{m}$ indefinitely under ground-plane vibration.

TEIL 1 Dynamische Modellierung & Inverses-Pendel-Physik

Ein zweirädriger Balancierroboter (TWSBR) ist ein nichtlineares, unteraktuiertes mechatronisches System. Es verfügt über 3 Freiheitsgrade (Kippwinkel $\theta$, Radpositionen $\phi_L, \phi_R$, Gierwinkel $\psi$), wird jedoch nur durch zwei Antriebsmotoren (Drehmomente $\tau_L, \tau_R$) angesteuert.

Über die Euler-Lagrange-Bewegungsgleichungen lässt sich das System um den instabilen vertikalen Gleichgewichtspunkt $(\theta = 0, \dot{\theta} = 0)$ linearisieren:

% Lineare Zustandsraumdarstellung um theta = 0:
% Zustandsvektor: x = [Position; Geschwindigkeit; Neigungswinkel; Winkelgeschwindigkeit]^T
% dx/dt = A*x + B*u
% y     = C*x + D*u

Kippt das Chassis nach vorne ($+\theta$), müssen die Räder nach vorne beschleunigen ($+\ddot{x}$), um ein aufrichtendes Trägheitsmoment zu erzeugen.

Zentrale Erkenntnis: Die Position kann nicht stabilisiert werden, ohne den Neigungswinkel anzupassen. Ein einkreisiger PID-Regler scheitert, weshalb die kaskadierte Zweikreis-Architektur mathematisch zwingend erforderlich ist.

TEIL 2 Kaskadierte Zweikreis-Regelungsarchitektur (500Hz / 50Hz)

Die Architektur entkoppelt die Dynamik in zwei Frequenzbereiche:

  • Schneller Innenkreis (Neigungs-/Balancierkreis - 500 Hz): Verarbeitet Neigungswinkelfehler $e_\theta$ und Winkelgeschwindigkeit $\dot{\theta}$. Gibt PWM-/Drehmomentbefehle an die Motoren aus.
  • Langsamer Außenkreis (Positions-/Geschwindigkeitskreis - 50 Hz): Berechnet aus dem Positionsfehler $e_x$ den Soll-Neigungswinkel $\theta_{\text{ref}}$ für den Innenkreis.
% Mathematische Gleichungen:
% Innenkreis: tau(t) = Kp_theta * (theta_ref - theta) + Kd_theta * (0 - theta_dot)
% Außenkreis: theta_ref(t) = Kp_x * (x_ref - x) + Ki_x * integral(x_ref - x) + Kd_x * (0 - x_dot)
% Winkelbegrenzung: theta_ref = max(-12 deg, min(+12 deg, theta_ref))

TEIL 4 ESP32 FreeRTOS Firmware & Sensorfusions-Implementierung

Auf dem ESP32 läuft die Regelung im Dual-Core-Betrieb: Core 1 führt den zeitkritischen 500Hz-Regeltask aus, während Core 0 Telemetrie und Fernsteuerung übernimmt.

// 500Hz Regelungs-Task auf Core 1 via FreeRTOS
float dt = 0.002f;
pitch_angle = 0.98f * (pitch_angle + gyro_rate * dt) + 0.02f * accel_angle;
float torque_pwm = Kp_pitch * (theta_ref - pitch_angle) - Kd_pitch * gyro_rate;
apply_motor_pwm(torque_pwm);

TEIL 5 Systematisches Einstellprotokoll & Anti-Windup-Strategie

  1. Schritt 1 (Innenkreis isolieren): Außenkreis deaktivieren. $K_p^\theta$ schrittweise erhöhen, bis das Chassis auf Stöße reagiert.
  2. Schritt 2 (Dämpfung): $K_d^\theta$ anheben, um Schwingungen aperiodisch zu dämpfen.
  3. Schritt 3 (Geschwindigkeitsdämpfung): $K_d^x$ im Außenkreis aktivieren, um Wegdriften zu verhindern.
  4. Schritt 4 (Positionsrückführung): $K_p^x$ mit harter Begrenzung auf $\theta_{\text{ref}} \in [-12^\circ, +12^\circ]$ hinzuschalten.
  5. Schritt 5 (I-Anteil mit Anti-Windup): $K_i^x$ nur bei kleinen Abweichungen aktivieren.
